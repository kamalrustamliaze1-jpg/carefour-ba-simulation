# 08 · Use Cases & User Stories

## Use Cases

| UC ID | Name | Actor | Description |
|---|---|---|---|
| UC-01 | View regional revenue panel | Regional Sales Director | Views revenue, transaction, and unit metrics for a selected region and period. |
| UC-02 | Loyalty segment analysis | Loyalty Program Owner | Compares Basic/Silver/Gold/Platinum segments and drills into the deep-dive panel. |
| UC-03 | Returns exclusion report | Finance Controller | Verifies how returned orders are excluded from the main report. |
| UC-04 | Track category performance | Category Manager | Tracks revenue and unit sales by product category. |
| UC-05 | Review anomaly alerts | Business Analyst | Investigates alerts triggered when reconciliation discrepancy exceeds 0.5%. |
| UC-06 | Export dashboard | Any user | Exports the current view as PDF or PPT. |

## User Stories

- **US-01:** As the Regional Sales Director, I want to compare all regions' revenue on one screen so I can make fast resource-allocation decisions.
- **US-02:** As the Loyalty Program Owner, I want to understand why the Gold segment generates less revenue than others so I can plan a targeted campaign.
- **US-03:** As the Finance Controller, I want to see how returned orders are excluded from revenue so I can be confident in report accuracy.
- **US-04:** As a Store Manager, I want to see only my own store's performance so that other stores' sensitive data stays inaccessible.
- **US-05:** As a Business Analyst, I want to receive alerts about automatic reconciliation errors so I can catch data issues early.
- **US-06:** As a Category Manager, I want to view the monthly sales trend in a line chart so I can forecast seasonal demand.
